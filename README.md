# Лиды — записные книжки

Личное приложение: книжки, коллекции, заметки, фото, шаблоны, поиск, PIN и резервная копия в файл.
Все записи хранятся только на телефоне. В репозитории лежит только код.

Файлы (все в корне репозитория): index.html, manifest.webmanifest, sw.js, jszip.min.js, lidy.png, icon-192.png, icon-512.png, apple-touch-icon.png
